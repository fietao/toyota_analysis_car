## สรุปสั้นที่สุด

ระบบพร้อมส่งมอบแล้ว ใช้งานหลักมี 2 อย่าง:

1. เปิดแดชบอร์ดเพื่อดูข้อมูลรถ
2. อัปเดตข้อมูลรายเดือนเมื่อได้ไฟล์ Excel ใหม่จากกรมขนส่ง

ผู้ดูแลคนใหม่ไม่ต้องเขียนโค้ด ไม่ต้องใช้ Git และไม่ต้องเปิดไฟล์ JSON

## ไฟล์ที่ควรรู้จัก

| ไฟล์ | ใช้ทำอะไร |
|---|---|
| `TAKEOVER.bat` | เมนูเริ่มต้นสำหรับคนรับช่วงต่อ ใช้ติดตั้ง เปิดเว็บ และเปิดคู่มือ |
| `frontend\RUN.bat` | เปิดแดชบอร์ดที่ `http://localhost:3001` |
| `MONTHLY_UPDATE.bat` | อัปเดตข้อมูลรายเดือน หลังจากวางไฟล์ Excel 2 ไฟล์แล้ว |
| `docs\THAI_OPERATOR_MONTHLY_GUIDE.md` | คู่มือรายเดือนแบบละเอียด |
| `backend\config\model_powertrain_review.csv` | ไฟล์เดียวที่ผู้ดูแลอาจต้องแก้ เมื่อมีรุ่นรถใหม่รอตรวจ |

## เปิดใช้งานครั้งแรก

1. เปิดโฟลเดอร์ `C:\dev\ai-reading-car-analysis`
2. ดับเบิลคลิก `TAKEOVER.bat`
3. ถ้าเป็นเครื่องใหม่ ให้เลือกข้อ `7` (First-time install)
4. ถ้าเคยติดตั้งแล้ว ให้เลือกข้อ `8` (Refresh project dependencies only)
5. เมื่อติดตั้งเสร็จ ให้เลือกข้อ `1` เพื่อเปิดแดชบอร์ด (Start the dashboard)

ถ้าเว็บไม่เปิด ให้ลองเข้าเองที่:

```text
http://localhost:3001
```

## งานประจำเดือน

เมื่อได้ไฟล์ Excel จากกรมขนส่ง ให้ทำตามนี้:

1. วางไฟล์ Excel ทั้ง 2 ไฟล์ไว้ใน `backend\raw data\`
2. ปิด Excel ทุกหน้าต่าง
3. ดับเบิลคลิก `MONTHLY_UPDATE.bat`
4. รอจนหน้าต่างทำงานเสร็จ ห้ามปิดกลางทาง
5. อ่านไฟล์สรุปที่ `reports\monthly_operator_summary.txt`

ระบบจะตรวจข้อมูลก่อนเผยแพร่ ถ้ารันไม่ผ่าน ข้อมูลเก่าจะยังอยู่ ไม่พังเว็บ

## ถ้ามีรุ่นรถรอตรวจ

บางเดือนระบบอาจบอกว่ามีรุ่นรถใหม่รอตรวจ เป็นเรื่องปกติ

ให้เปิดไฟล์นี้เท่านั้น:

```text
backend\config\model_powertrain_review.csv
```

สิ่งที่ต้องกรอกเมื่อมั่นใจว่ารุ่นนั้นเป็น BEV:

| ช่อง | ต้องใส่อะไร |
|---|---|
| `candidate_powertrain` | ใส่ `BEV` |
| `review_status` | ใส่ `approved` |
| `evidence` | ใส่หลักฐาน เช่น ลิงก์หรือชื่อโบรชัวร์ |
| `reviewer` | ใส่ชื่อคนตรวจ |
| `reviewed_at` | ใส่วันที่แบบ `YYYY-MM-DD` |

ถ้าไม่มั่นใจ ให้ปล่อยเป็น `pending` ไว้ก่อน

## ห้ามทำ

- ห้ามเดาว่ารุ่นไหนเป็น BEV จากชื่อรุ่นอย่างเดียว
- ห้ามใช้คำว่า `EV`; ต้องใช้ `BEV`
- ห้ามแก้ไฟล์ `.py`, `.json`, หรือ `.bat`
- ห้ามลบไฟล์ใน `backend\config\`
- ห้ามเปิด Excel ค้างไว้ตอนรัน `MONTHLY_UPDATE.bat`
- ห้ามรัน `MONTHLY_UPDATE.bat` ถ้ายังไม่ได้ตั้งใจอัปเดตข้อมูลเดือนใหม่

## งานที่เพิ่งทำเสร็จในรอบนี้

หน้า Manual Report ที่ `/report/` ใช้ง่ายขึ้นแล้ว:

- ตารางเน้นการเทียบข้อมูลก่อน
- แถวรายละเอียดรายเดือนกดขยายดูได้
- Sheet `8.Model Top Rank` ซ่อนคอลัมน์เดือนล่าสุดไว้ก่อน เพื่อลดความกว้างของตาราง
- มีปุ่ม `Show Jun'69` / `Hide Jun'69` โดยข้อความเดือนและปีมาจากข้อมูลจริง ไม่ได้พิมพ์ค้างไว้ในโค้ด

ตรวจแล้วผ่าน:

- Frontend lint
- Frontend build
- Frontend tests
- เปิดเว็บจริงและตรวจหน้า `/report/`

รอบนี้ไม่ได้อัปเดตข้อมูลรายเดือน และไม่ได้รัน `MONTHLY_UPDATE.bat`

## ถ้ามีปัญหาให้บอกคนเทคนิคแบบนี้

ส่ง 3 อย่างนี้ให้คนเทคนิค:

1. รูปหน้าจอ error
2. ไฟล์ `reports\monthly_operator_summary.txt`
3. ไฟล์ล่าสุดในโฟลเดอร์ `logs\`

ไม่ต้องแก้ไฟล์เองถ้าไม่แน่ใจ
